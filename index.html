How it works: three steps. Start at whichever one fits.

  1. 1Assess
    Find where AI helps
  2. 2Transform
    Get people using it
  3. 3Build
    Build the tools
1

Assess. Find where AI helps.

Understand the work before buying tools.

  • A process map of how the work gets done today, built from interviews with the people doing it.
  • A data map showing where your data is and what's usable.
  • A ranked list of AI uses, by value and effort.
  • Rules for what data can go where.

Result: A roadmap of what to do first, what each step needs, and who owns it.

2

Transform. Get people using it.

Licenses alone don't change how work gets done.

  • Training built around each team's actual work.
  • Governance and tools that IT, legal, and finance can approve.
  • Usage tracking to measure who uses what, and whether it helps.
  • An idea intake process so teams can suggest new uses and see the good ones built.

Result: AI as part of everyday work, with numbers to show it.

3

Build. Build the tools.

Working tools inside real workflows.

  • Agents and automations for business work like month-end close and contract review, and for engineering work like testing and incident response.
  • Any vendor or model that fits. No product to sell.
  • Documentation and handoff so your team can run it.

Result: Software your team uses and can maintain.
